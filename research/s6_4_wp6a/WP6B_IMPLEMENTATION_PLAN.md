## Engineering acceptance tests

| Proposed test ID | Stimulus and assertion |
|---|---|
| `FND_LEGACY_BYTES` | Repeat RM-01 sentinels, original warm failures, WP-4 dose windows and WP-5 founder control from legacy saves. Exact checkpoints, canonical bytes, hashes, RNG, budget signs and result times. All inherited CTest remain. |
| `FND_CONFIG_MASS_OVERFLOW` | Oversubscribed wet mass, out-of-scope model ID, incompatible clock/rate/capacity or excessive integrated quantities. Fail before registration, preserving exact input world. |
| `FND_CONVERSION` | Start with funded buffer and mass; compare several refill ticks and no more fuel. Validate chemical plus active energy closure and a single irreversible substrate debit. Exercise rejected conversion at full capacity. |
| `FND_BIRTH_COMMIT` | Funded and refused births at exact reserve/headroom thresholds. Force allocation/event failure after preflight and after debit under fault harness. Compare all states, queue IDs, RNG and canonical journal, then retry. |
| `FND_OPENING_BOUT` | First eligible tick, last short-spaced tick, and first later attempt with one birth maximum per tick. Advance or restore around the half-open window. Refuse additional eggs when a limiting stock is consumed and keep the exact scheduled attempts. |
| `FND_DEATH_PRIORITY` | Separate embryo energy and water exact ties; both zero; available late crop or lipid at zero; birth/care request on maternal or child death tick. Record correct terminal event and zero further spending. |
| `FND_LARVA_CAP` | Cap reached with missing tissue, later positive assimilation permits transition, starvation and no-dose controls. No progress overshoot, fabricated pupal reserve or same-time recursion. |
| `FND_PUPAL_MARGIN` | Exact closed-stage water/energy cost and one-quantum residual. Exhaustion wins the tie. Successful emergence preserves identity and residual lipid without a new input. |
| `FND_LOCAL_FEED` | Reachable, wall-separated, dead/pupated receiver, lost custody, exhausted donor, full recipient, and two donors at one timestamp. Zero/refused outcomes leave inventories and fact identity correct. |
| `FND_FOLLOW_UP` | Same early-worker actions and switches after actual eclosion. Verify no global worker signal and no first-worker birth shortcut. Retain supply-access and decline controls. |
| `FND_EXACT_RESTORE` | Save before birth, immediately after transfer, mid-conversion carry, at blocked progression and just before a tie. Full checkpoint and segmented frame restore followed by varied advancement partitions and observer on/off. Compare byte-for-byte. |
| `FND_CORRUPT_OR_UNSUPPORTED` | Invalid typed reserve/participant/mass, unknown schema/physics/codec, corrupt anchor and stale reader. No partial mutation or misleading history. Preserve old manifest publication during injected failure. |
| `FND_BOUNDED_COST` | Inspect per-entity state size, event counts, refill/decision latency, queue occupancy, history, checkpoint, restore and memory. Use the same source and frozen input for paired observations. Document operations with changed event counts per positive outcome separately. |

For performance, preserve the current native admission, pairing, exact workload hashes, TD-01/TD-08 thresholds and existing observer budgets. For F1 additionally freeze profiling before execution and record initialization, each advance phase, per-active and terminal state bytes, event kinds/bytes, peak queue and RSS, checkpoint and reopen. Compare same-case observer on/off and uninterrupted/restored, with identical physics and facts. Compare model alternatives by both absolute cost and workload-normalized cost. Treat altered event volume as a measured consequence. Use the existing owner queue and no extra decision tick. Reject unbounded event/queue growth, change to legacy performance gates or omitted facts. Record any durable flush tails separately within total runtime.
