The activity, recruitment and finite maternal water contrasts did not change this endpoint over day 55 in this panel. This is a model diagnosis. Existing thermal, wet-cotton and dietary experimental data do not identify a universal larval allocation probability. Avoid adding a new physiological variable or inferring free water.

The configuration uses the original shaft and dogleg geometry and the original sources. The supplemental isolation pocket belongs to the factorial experiment. It is omitted here. The opt-in profile changes no old file or model semantics. Finite supplemental water remains a separate candidate condition.
