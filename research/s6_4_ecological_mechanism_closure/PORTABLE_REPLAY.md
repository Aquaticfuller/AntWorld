# Portable trail arithmetic and replay

The first release evidence workflow for physics 24 failed the Linux byte comparison at the 150-day Borisovka shaft witness. The failure was reproduced with the native Linux executable. Windows and Linux wrote 591,390 facts with the same byte length, the same event and action order, and the same input checkpoint. Exactly one fact differs. The first differing byte is offset 85,735,355 in the length-prefixed stream, at fact 421,676. It belongs to the positive trail-deposit field. The Windows value is 1.0 and the Linux value is 0.9999999999999999. The uninterrupted and SQLite-restored Linux bytes agree. The diagnostic compares every byte outside the deposit field as well. Both original Linux outputs remain available to recalculate the failure. ## Numerical and version change

Physics 25 replaces the opt-in surface field's use of implementation-dependent `exp` and `log` with a range-reduced exponential. Exact binary scaling applies the whole half-lives. Explicit fused arithmetic evaluates an 18-term Taylor series over the remaining fractional half-life. The CTest covers fractional and whole values against `exp2` with relative tolerance 2 × 10⁻¹⁵. The stored deposit result uses a 2⁻³⁶-unit binary concentration lattice with defined saturation. Legal values below that lattice retain their existing representable concentrations. The stored value is clamped to its prior amount and configured cap. Runtime reads, maintenance, deposits and committed-fact validation use the same policy. Existing half-life, cutoffs, weights and positive payload rules remain at their frozen input values. The lattice is a numerical representation of an uncalibrated field. [Implementation](../../cpp/src/surface_internal.hpp) [Regression](../../cpp/tests/test_ecological_closure.cpp)

`AWCKPTM` schema 22 distinguishes physics 24 from physics 25 in its header. The `AWFACT09` block continues to preserve the same event layout. Opt-in worlds can use either contract. Loading an earlier world selects its original numerical policy without conversion. Older non-ecological worlds keep their encoding, state and results. Physics 24 retains its cross-platform last-bit limitation. Its evidence remains public and is decoded under the original policy.

A final SQLite regression reproduced a compatible-prefix defect before any trail deposits differed. It was possible to append a later checkpoint carrying the other physics ID to a published ecological world because both versions share `AWFACT09`. Publication now requires the same ecological checkpoint schema and physics fields. Recovery also checks those fields along the anchor chain. The test rejects replacement in either direction, checks the original publication after rejection and verifies successful continuation under each world's original policy. This changes the acceptance of a mixed-policy publication. The committed simulation histories and existing valid checkpoint encodings stay byte-identical.
