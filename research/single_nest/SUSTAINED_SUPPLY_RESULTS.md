## Reproduction

The native runner reads committed facts in pages, checks food, energy, lipid and soil balances, and compacts resident history in memory. Compact fixtures and compressed receipts retain the identifiers, physical starting conditions, software seeds, censoring, individual eclosions and deaths. To reproduce on an existing live build, run these from the repository root.

```powershell
py -3 -B tools/build_m0_live.py
py -3 -B -m tools.verify_supply_continuity --version 73 --version 76 --version 78 --verify-restore
py -3 -B -m tools.verify_supply_continuity --first-worker --verify-restore
py -3 -B -m tools.verify_supply_continuity --energy-seed 3 --verify-restore
py -3 -B -m tools.verify_supply_continuity --energy-seed 17 --verify-restore
py -3 -B -m tools.verify_supply_continuity --energy-seed 17 --version 81 --verify-restore
py -3 -B -m tools.verify_supply_continuity --archive
py -3 -B -m tools.verify_supply_continuity --panel research/single_nest/SUSTAINED_SUPPLY_TRIALS.jsonl.gz
py -3 -B -m tools.measure_first_meal --model familiar-site-detour --seed 2 --supply nearby --days 730 --feeding-continuity --trace-flux --include-water
```

In the live viewer select **Supply continuity trial · Physics 80** in closed-nest settings to observe the experimental policy from birth.
