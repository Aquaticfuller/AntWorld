# Brood care state machine audit

The [pre-implementation audit](../../docs/59_S6_3_3_2_Care_Design_Audit.md) pins the old code and the design assumptions. This table maps the frozen fidelity implementation to the [source and parameter register](BROOD_MOTION_EVIDENCE_AND_PARAMETERS.md). The simulation contracts apply to Lasius niger engineering worlds. F indicates an engineering rule with an uncalibrated effect size.

| State or decision | Source and actual guard | Biological interpretation and evidence |
| --- | --- | --- |
| No care owner | `ecology.cpp::resolve_autonomy_wakes` waits for a normal reevaluation. A worker must satisfy minimum program time, ownership and urgency constraints. A queen can take only the caste-specific care branch. | Workers and queens both retrieve displaced brood in B02. B01 shows that queens can change care with worker presence. Motor lease and ordinary scheduler cadence are F. |
| First enrollment / shelter | `care.cpp::enable_brood_care` requires local shelter contact. `start_autonomous_care` first enrolls at the actual depot. Only a previously enrolled individual can continue returning from elsewhere. | B02 acclimates animals to a familiar nest tube. The exact remembered position and radius are F. Odor exposure and entrance recognition remain NOT IMPLEMENTED. |
| Discover and screen | `care.cpp::resolve_care_wakes` enumerates living reachable neighbors inside the profile radius, with stable order. It filters species context, stage, shelter displacement and reserved targets. Ordinary care requires the same colony. The neutral apparatus admits displaced conspecific larvae/pupae. | B02 supports retrieval of both origins in its apparatus. Lenoir reports context-dependent recognition. The assay flag is a scoped engineering representation. Chemical identity, habituation and adoption remain NOT IMPLEMENTED. |
| Inactive / initiate | Below the inherited quarter-capacity condition or after a failed local initiation draw, a dedicated actor can enter an inactive bout. The decision uses keyed individual RNG. An integrated actor without a valid act releases its lease. | No matched observation supports the quarter-capacity condition, initiation probability, inactivity meaning or waiting time. Inactive observations distinguish modeled motor time from a task label. |
| Walk / search | `resolve_care_wakes` picks one local cardinal direction when a dedicated actor has no eligible brood. Timed mode has at most eight steps per search sequence. Every segment receives a fresh local decision. | Repeated exploration is observed in Carthy. Cardinal directions, finite search budget and the absence of heading persistence during untargeted search are F. |
| ApproachBrood | A displaced focus survives across decisions while it is visible, eligible and reachable. `care_toward` uses one bounded step toward that local observation. Loss of visibility clears the focus. | Local approach and antennal inspection have direct observational support. The 6 mm radius, 2 mm handling contact and exact vector direction are F. |
| PickUpBrood | `execute_care_action` rechecks stage, distance, geometry, available lock and loaded clearance. Beginning reserves the live target. Completing creates committed custody and an evidenced pickup site, with no position change. | Pickup before return is directly observed. The 500 ms handling delay, one-load rule and footprint are engineering proxies. Collision constraints apply to both members. |
| TransportBrood | The live held target and carrier move together. The route aims in bounded segments toward the actor's own experienced shelter using a separate loaded speed. Geometry, arena and collision checks run at start, end and on geometry changes. | Carthy's two tracked workers show repeated physical returns and differences in route shape with altered visual cues. Direction from exact shelter memory and constant segment speed are F. There is no visual or brood-trail orientation model. |
| PlaceBrood | Only the actual holder inside the brood shelter radius can complete release. A separate placement clock and committed terminal act precede credit. | B02 counts retrieval into a familiar tube. The radius substitutes for that aperture. Handling time is unmeasured. |
| RevisitBroodSite | A dedicated actor can use one position already visited during a physical pickup. If another displaced target appears in local view it can approach it. Arrival, interruption or loss of the episode clears the relevant memory. | Lenoir and Carthy observe return journeys after delivery. Which cues and memory are used in this apparatus remains unresolved. The 1 s pause is F. |
| Inspect / Arrange / Clean | Settled reachable brood is eligible after initiation. The selected act has a real duration. Arrangement moves the target only after spatial validation. | B01 supports the observed category of active tending. Relative frequencies, biomechanics and pathogen consequences remain uncalibrated. Pathogen dynamics are NOT IMPLEMENTED. |
| FeedBrood | Same-colony larval nutrition uses actual local demand, crop supply and the existing trophallaxis transaction. A failed transfer carries no nutrients. | Active handling and committed food transfer are distinct. Timing and mass follow inherited physiological fixtures and retain SD-04/SD-08. |
| CloseWorkerContact | A queen can select contact with a reachable nearby adult worker. Only completion refreshes her cue. Time since the last completed contact influences her next initiation draw, with finite decay. | B01 supports reversible social effects at the intervention level. The model mediator, 6 h horizon, 0.8 ceiling and 0.25 contact lottery remain F. |
| ReturnToCareShelter / yield | An integrated lease covers one handling episode. Normal reevaluation remains scheduled. The motor returns physically to the remembered depot, then yields. A blocked step yields and a later eligible wake can retry a valid step. | The cooperative software boundary is F. Existing foraging routes retain identity and can resume at a valid route endpoint. No long-range detour planner was added. |
| Interruption | A conflicting claim, changed geometry, death/stage change or funded queen laying can interrupt an act. The journal keeps elapsed active intervals and releases any reservation. Positions stay at the last committed segment. | The reason records an engineering causal condition. The funded laying branch uses the inherited resource and timing equations. Care timing in living founding queens needs independent measurements. |

The versioned fact vocabulary separates opportunity, selection, start, completion and interruption. A care-state residence interval is available independently of measured act duration. Biological comparisons use actual handling or placement events. Scans and track reconstruction never drive behavior.

Current shape and timing gaps include mixed brood recognition chemistry, queen and callow development, coarse surface grids, continuous curvature and acceleration, carry fatigue, visual background cues, relative body/load dimensions, thermal relocation and microhabitat preference. The 3D sweep contract remains authoritative when geometry is present. On a surface-only grid, safe translations require a legal step between cell centers that fits the configured stride. These limits are separately recorded in the [integration contract](CARE_AUTONOMY_INTEGRATION.md).
