## Version and recovery boundaries

Keep every legacy checkpoint, state frame and event-block byte path. F1 has an explicit schema 15, physics 17, F1 profile version 1, and a candidate checkpoint section with the exact inner legacy feature descriptor. A frame binds its published history prefix. Introduce candidate typed facts for declaration, founder reserve input, funded egg stock, lipid conversion and maternal ration. The F1 event-block codec uses its own version marker. Bound and validate payload, participant identity, ledger, event order, ownership, and malformed data before restoration. The SQLite tables and publication transaction retain their existing meanings. Checkpoints for unsupported versions must fail before replacing a world. F1 disablement requires a legacy baseline or another world. No migration of legacy biology or hidden profile fallback is permitted.
