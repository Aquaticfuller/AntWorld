## Decisions and scope

- ADR-S4-01: InitialSolid plus an ordered Excavate/Fill log remains the sole geometry authority (option A). The first exact kernel uses parameterized axis-aligned boxes on a configurable physical coordinate quantum, default 0.5 mm. This is a parameter precision policy, not an authoritative voxel occupancy store. Seed voids and immutable rocks are initial conditions. Curved tools, smooth meshes, pose-dependent ellipsoids and compaction of authority are deferred explicitly; boxes allow exact overlap accounting and sharp thin-wall tests before approximate curved integration.
- ADR-S4-02: homogeneous fixture soil has explicit dry/water micrograms per cubic coordinate quantum (defaults 100/25 ug; ENGINEERING_FIXTURE). Exact coordinate partitioning of relevant box boundaries measures only currently occupied soil or currently empty fill volume. No rounded mass is created on repeated/overlapping removal. Each successful dig creates an identified parcel linked to the edit/source event; carrying, physical loose deposition, pickup and fill preserve dry and water quantities. Loose deposited parcels are inventories at actual locations; only a supplied Fill operation makes them authoritative compacted solid. Granular pile collisions and compaction variation are not claimed.
- ADR-S4-03: edit AABBs are indexed into bounded spatial buckets. Querying a point/local volume considers overlapping indexed edits in order, rather than scanning every lifetime edit. Exact local partition complexity has an explicit host budget; exhaustion fails atomically, never approximates a passage as empty. All unsigned volume/mass arithmetic is checked.
- ADR-S4-04: navigation uses a conservative axis-aligned body envelope, larger while carrying food or soil. Swept envelopes are checked against current authoritative material, including thin walls. Versioned route results contain real 3D steps and are revalidated after edits; fill can delete connectivity. Empty top-view overlap is irrelevant. Coarse route search is bounded, may reject an otherwise possible path, and never grants an ant global food locations. Contact and local sensing use the same barrier-aware spatial service.
- ADR-S4-05: local SDF bricks are disposable, source-versioned caches. Obtain true signed distance within a declared narrow band from the local exact box arrangement, not the magnitude of an unredistanced min/max CSG expression. Cache construction is an explicit single-writer operation, never a side effect of reads; geometry edits dirty intersecting bricks plus clearance/SDF halo across seams. Cache eviction/reconstruction cannot change geometry, material or biological continuation. No rendering mesh is required in this stage.
- ADR-S4-06: introduce a generic local-neighborhood interface with spatial buckets for geometry-enabled worlds and exact distance/barrier filtering. Nursing choices remain local and preserve the original private RNG/order semantics when geometry is absent. Retain SD-04's seed-43 negative result. Measure dense real-contact cost separately from distant population scanning; an index cannot eliminate the true cost of all co-located neighbors.
- ADR-S4-07: extend the validated action transaction with local excavation, soil transport/deposition/pickup/fill and a minimal individual excavation loop. Decisions use only local frontiers/steps and bounded experienced return traces to the known depot. No complete nest template or global task allocator. Runtime pause/switch/death cancels owned work and preserves soil. All uncalibrated behavior, body size, effort and material parameters remain ENGINEERING_FIXTURE.
- ADR-S4-08: schema/physics advance to 5/7; earlier saves reject explicitly. Persist initial solid, seed/rock shapes, ordered edits, provenance, parcels, ledgers, pending requests, excavation state and stable counters. Reconstruct derived indices/SDF/nav; do not make cached occupancy the saved truth. Extend touched-entry undo journals, not State copies. Historical contact validation uses the geometry revision at the event, not the final filled geometry.
