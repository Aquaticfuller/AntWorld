## Metric definitions

- `unmet_protein_ug`: sum of positive larval requirement minus own tissue and crop protein for **living current larvae**. Eggs, pupae and dead individuals do not emit that modeled cue. `unemerged_brood` separately retains all seeded brood lacking an actual emergence, including deaths.
- `adult_crop_protein_ug`: actual crop protein of living adults; tissue is excluded. `dead_crop_protein_ug` is retained physical inventory, no longer a living transferable source. Introduced mass includes the declared 200 ug pupal tissue. Total accounted ingredients/energy/soil include dead inventories and explicit sinks.
- At 10 s, an observer exhaustively checks actual distance, crop capacity and solid-qualified contact. `accessible_demand_ug` counts each needy larva once if at least one living adult holds compatible protein in contact. `accessible_supply_ug` counts each such donor's crop protein once. These are coexistence diagnostics, not a solved flow allocation or a promise every demand can be filled; neither value enters behavior. Between these samples the two columns carry their last observed value, with `accessible_sample=0` explicitly marking carry-forward.
- Integrals use the left-rectangle rule on the declared grid: 1 s for unmet demand, 10 s for reachable demand/supply, in ug*s. This is sampled exposure, not claimed continuous exact integration. Endpoint death cannot conceal earlier unmet demand.
- `gift_attempts` counts actual resolved scheduled Trophallaxis sources. The observer records due source/kind before advancement and matches the committed resolution, so rejected gifts are distinguishable from other rejected actions. `gift_success`, `gift_partial`, `gift_failed` partition attempts; a canceled unexecuted proposal is not a resolution. Completion rate is `(success + partial) / attempts`, undefined with zero attempts. Protein given counts real transferred protein, not requested amount.
- `program_switches` counts actual BehaviorChanged facts, including initial activation. `nurse_exits_with_sampled_work` counts former Nurses leaving while the actual reconsideration sample contains ingredient-compatible work. It includes urgent exits, which are separately marked. Rates use the stated observed duration, not an inferred daily biology rate.
- Decision rows reconstruct the actual private sample only when the committed AutonomyDecision reports sampling. Reschedule changes programs but not positions, life stages or inventories, so its end-boundary cue reconstruction preserves the choice inputs. Rows without a sample do not invent perceived demand. `can_switch` checks actual depot/stationary ownership and empty food/soil cargo; `ready` checks the original minimum duration. `blocked_travel_decisions` and `minimum_time_decisions` separate these gates. `crowded` and `reachable_soil` reconstruct the existing sampled crowding and six-direction local soil cue, not a new excavation feedback.
- Initial-worker living, active-program and away-from-depot milliseconds integrate actual event boundaries for the original adult worker IDs. Active means Nurse/Forage/Excavate ownership, not proof of continuous locomotion or successful work. Moves and actual excavated volume are separate. Later-emerged brood and the queen are excluded from these denominators.
- Density arms alter initial worker count, total declared reserves and brood IDs, in addition to contact opportunity. They are not a pure density intervention at fixed total energy/identity. Each within-arm policy comparison retains identical identities, resources and geometry.

The analysis uses complete fixed seed sets, paired differences, seed bootstrap 4,096 resamples with seed 6106, and mirrors averaged within seed. Execution replicas are not extra independent samples. All original negative outcomes remain. Species calibration, fatigue/rest feedback, task-conditioned local demand signaling, long-range recruitment and realistic nest morphology remain separate scientific questions; this batch must not invent them to obtain favorable plots.

## Execution-only partitioning

After final isolated performance sampling, the long ecology runners gained an optional `FIRST_SEED` argument. It selects a contiguous interval inside the same frozen seed set; defaults and per-world execution are unchanged. Independent processes can execute intervals on separate cores. The merger requires a gap-free, nonoverlapping complete grid, identical configurations and complete per-seed row counts, then concatenates every row in original seed order. It retains the original binary/SQLite histories and records source intervals. This changes host execution concurrency only, not biology, replication, seed selection or the already completed acceptance performance measurements. The interrupted serial prefixes remain local evidence and are compared against completed repeated cases; they are not extra statistical replicates or substituted favorable results. Final figures use each frozen case once.
