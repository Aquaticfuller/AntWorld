# AntWorld｜游戏总体设计（v0.4）

## 1. 愿景

一个以自然生态演化为核心的低操作、长期可持续游玩的蚂蚁世界。玩家是温和照料者和观察者，从一窝蚂蚁开始，拥有可以观察数日、数年乃至世代更替的开放微观生态系统。游戏没有副本主线、强制胜负与固定敌人波次。蚁巢可能成长、迁巢、衰退、婚飞产生新群落，最终消亡；世界仍然继续存在。

核心承诺：**你不是蚂蚁社会的国王；生态运行不需要你指挥。**

## 2. 三根支柱

1. **生态模拟**：每只蚂蚁的生命状态、局部感知、记忆与行为；群体行为由局部互动涌现。
2. **数据与历史**：任何时刻都能理解宏观趋势，也能跟随普通工蚁回顾它的一生；历史回放区分真实记录与推测重现。
3. **AI Game Master**：稳定身份、跨世界记忆、主动观察、统计解读、自然纪录片旁白；通过相同玩家工具控制视角、时间和环境。

## 3. 世界与开局

- **世界类型**：自然生长的连续开放生态；并非仅供装饰的生态箱或逐关解锁地图。
- **首版生境**：温带草地与林缘，后续可选花园、森林、干旱草地、沙漠和其他地域。
- **首版空间**：24m × 24m = 576m²，2m × 2m 候选分块，能够向外扩展；多个自主蚁群同在局部区域。
- **首个重点蚁种**：黑园蚁 *Lasius niger*。后续不同蚁种需要真正不同的食性、建群、挖掘、繁殖和生态交互。
- **开局可选**：婚飞后独立建群的蚁后 / 少量工蚁的幼小蚁群（默认） / 成熟群落。
- **生态层级**：蚂蚁具体个体最精细；植物、蚜虫、普通昆虫与捕食者具有自主种群与资源动态，但不一定逐一个体同精度。

## 4. 体验节奏

- **秒—分钟**：跟随个体、看触角接触、搬食、交哺、育幼、挖掘、争斗、休息。
- **天—月**：观察食物路径、幼虫发育、工蚁分工、巢室扩张、天气与生态关系。
- **年—世代**：观察婚飞、后代建群、生态竞争、环境演替、蚁巢的兴衰与谱系。
- **离线**：玩家按存档选择暂停、受限演化或持续演化；允许暂停/倍速；新启动时主动汇报离线变化。
- **未登录不等于停止存在**：符合离线配置时，世界独立演化；无后台服务时可在重新启动时计算合法离线时间段。

## 5. 玩家能做什么

- 任意缩放地表、旋转镜头、地下三维透明和自由剖切、跟随任意个体。
- 打开个体档案和群落面板，查询历史曲线、交哺网络、信息素热力图、种群统计与天气。
- 收藏单只蚂蚁，并允许 AI 自动深度追踪少量重要个体；设置提示阈值。
- 有限照料：食物、水、遮蔽物、环境干预与实验；蚂蚁行为不接受玩家直接指挥。
- 用 UI 或文字/语音对 Game Master 说明意图，由 GM 调用玩家等价工具，检索、分析、移动镜头、建立观察任务或合法改变环境。
- 允许多世界，全部世界共享一位 GM，但各自拥有独立存档、时间和实体 ID 命名空间。

## 6. 视觉设计

- 美术：精致自然的半写实微缩生态，不拟人化外形；远景清晰、近景具有真实微距质感。
- 真实三维坐标系，地下隧道允许水平、倾斜、转弯、分叉、交叠但不连通的不同高度层。
- 2.5D 是**观察方式**而不是生存空间降为 2D。地表倾斜俯视、地下透明、地下剖面、个体跟随切换看的是同一个世界。
- UI 默认克制。按需开启物种统计、龄级、信息素/温湿度/活动热力图。
- AI 三种呈现：安静、轻量旁白、完整交互；文字语音并重，无强制镜头劫持。

## 7. 生态闭环

气候/土壤→植物与猎物→食物资源→工蚁觅食→局部交哺与育幼→生命发育与新工蚁→更多资源需求、扩建、竞争；死亡、废弃物、天气变化和邻近蚁群反馈进生态。

环境事件主要来自自然模拟。GM 可生成合法情境建议，但未经预授权不能为了“好看”操纵生态结果。自然干预、玩家干预和 GM 干预都必须有来源标记。

## 8. 统计与历史

- 全部蚂蚁：唯一身份、发育阶段、出生、工作统计、主要事件、死亡与原因记录。
- 重点蚂蚁：更细轨迹和交互，支持历史回放；重点追踪只增加记录精度，不增加智力。
- 群落：工蚁/蚁后/卵/幼虫/蛹数量、年龄结构、资源、觅食、死亡、巢穴体积、空间影响/竞争及长期谱系。
- 可视化：时间序列、蚁群比较、空间热力图、生命时间线、巢穴剖面分析、事件跳转。
- 回放不能凭 AI 编造缺失的动作细节；未记录内容可以明确标为示意重现。

## 9. 无胜负的长期可玩性

没有任务刷怪和线性升级。长期内容来自：物种差异、自然季节、个体生命、邻近蚁群、环境资源动态、婚飞与谱系更替、玩家与 GM 的共同历史。

GM 会在合适时机提醒：你关注的蚂蚁死亡、巢穴有不同寻常的迁移、两个蚁群数量此消彼长、一次干预是否伴随生态改善；判断必须有事实依据。
