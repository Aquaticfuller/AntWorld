# AntWorld｜开放问题与待实验决策（v0.5）

## 立即讨论/研究

1. 巢内任务响应是否采用一个统一阈值体系，还是为育幼/挖掘/清洁分别建立行为调度器？怎样限制频繁切换？
2. 黑园蚁的幼体移动、清洁、挖掘等需要哪些本物种直接证据？如何区分从切叶蚁或其他蚁种迁移来的假设？
3. 幼体如何选择存放位置？个体有限路线/感知如何支持局部温湿度梯度优化而不获得全局上帝视角？
4. 蚁巢功能区域是否完全派生，还是保留仅用于观察/UI的“育幼室/仓储区/弃置区”标签？建议派生标签。
5. 动态挖掘细粒度：一份土量如何从三维土壤移除、工蚁背负、地表沉积，如何保证通道宽度和碰撞同步？
6. 哪些群体行为研究能用作真实标定；其物种、温湿度、实验规模是否适用于初始黑园蚁世界？

## 工程待验证

7. C++ Core 的 C ABI 设计、批量快照、线程模型与 Unity 数据交换。
8. 三维稀疏体积/SDF 与参数化通道实际组合，动态 mesh 和碰撞更新性能。
9. 远处个体事件时间推进与 LOD 切换的统计一致性测试。
10. 性能目标具体机器/CPU/GPU、测试平台与最大持久存档预算。
11. 2m chunk 是合理默认还是需要缩放、层级大块 + 局部细块？
12. 交哺、育幼、休息如何设计最小模型又保持真实统计。
13. SQLite 还是其他事件/时序存储，指标聚合、日志滚动和快照策略。
14. GM Agent Harness：Python/Hermes 或 C#/Microsoft Agent Framework，先做等价任务对比。
15. Agent 语音方案 STT/TTS、回声消除、打断和 API 消耗。

## 用户可后续决定的体验项

16. Game Master 的名字、具体初始性格、声音、是否有虚拟形象。
17. 首版细致生态对象/捕食者清单及难度/是否需要初始“纯观察”和“增强情境”预设。
18. 玩家放置食物、水、天气等操作的默认授权额度；灾害、引入物种等高级工具的确认流程。
19. 自动关注个体的数量预算、通知频率、历史保留策略、档案归档逻辑。
20. 世界扩张策略：边界外背景生态与新加载分块的长期事实衔接。

## 当前禁止默认假设

- 不因为设定了“全生态”就让所有昆虫都和蚂蚁同样逐个体精细模拟。
- 不因 Game Master 有性格就认为它拥有主观意识。
- 不因“有 AI”就让 LLM 自由指挥蚂蚁。
- 不因为某篇其他物种论文显示“幼体诱发挖掘”就将其定为黑园蚁的直接生理定律。
- 不把本阶段任何建议参数当作游戏里真实可用的已标定值。

## 三维建巢与地下环境（新增优先级）

21. 地下权威几何正式采用参数化挖掘编辑+局部SDF，还是稀疏砖块占用？应以 X1/X2/X4、性能和存档格式的共同测试选型。
22. 近场土壤工作精度在工蚁毫米尺度下如何选取？首版应验证 1–2mm 的活跃前缘示例，不应默认全巢室同精度。
23. 采用什么渐进巢室形成/通道净空判据，使其不用预置巢室蓝图，同时不会产生无法通行的尖锐碎片？
24. 建筑材料沉积、纯挖掘与回填的触发机制如何区分？各自需要什么黑园蚁直接证据？
25. 首版结构稳定性是最小厚度几何限制，还是加入土力学的有限近似？真实坍塌暂不承诺。
26. 巢内空气温湿度如何从土壤场和出入口交换推导，水何时真正进入连通空腔？
27. 如何保证导航和碰撞在网格异步重建时使用权威几何版本，避免短暂穿墙？
28. 能否通过数据公开仓库申请到黑园蚁 100日 3D CT 巢形、温度与挖掘土量原始数据？当前相关文件显示受限访问。

## v0.6 新增 / 决议后的开放问题

**已决议**：地下几何路线不再开放 A/B 方向选择，已经确定「有序参数化编辑 + 局部 SDF 缓存」。

**尚需验证/确认**：
- 工蚁单次 `ExcavatePatch` 的真实工作量与形状范围如何按 *Lasius niger* 证据标定？
- 何种扫掠原语、局部空腔形状既能保存任意真实小挖掘，又不会高频产生退化几何？
- 交叠体积与质量账使用哪种有误差界的算法？错误不变量应如何处理和恢复？
- `Portal` 和 `F_ant` 净空估计在极细通道、曲面交线和跨 chunk 边界是否可靠？
- 网格采样使用 Marching Cubes 还是 Dual Contouring？细节分级后如何保证薄壁、拼缝与法线？
- C++ 几何检查点/compaction 的合理策略以及历史 ID 保留/迁移；材料与水分字段如何在回填中更新？
- C ABI 分包、只读快照、异步 mesh、线程安全和客户端版本恢复机制的实测表现。

## v0.7：混合时间调度与持久状态待决问题

- 整数 SimTime 精度/最大历史跨度、同刻事件 Phase 与公平的 StableTieKey 如何固定为 ABI？
- 哪些个体行为要求严格事件驱动，哪些允许分块/批量感知更新？接触边界如何保证先唤醒？
- 大步积分遇到能量/发育/死亡的阈值交叉，如何定位到合法事件时刻？
- L0/L1/L2 升降精度的误差预算和跨边界交互怎么验证？

- 面向 Codex 的最小任务拆分以 `15_Minimal_Integrated_Vertical_Slice.md` 为候选，待本阶段规格确认后再开发。
