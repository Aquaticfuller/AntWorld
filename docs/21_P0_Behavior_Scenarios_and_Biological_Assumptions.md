# AntWorld｜P0 生物模型、场景配置与验证边界 v0.8

**定位**：把已有生物学专题转成工程实现可以参照的最小行为流程；本文件的参数均为**工程测试输入**，不是已标定的黑园蚁实测值。

## 1. 物种和生态模型分离

物种 `Lasius niger` 是用户已确认的首个重点物种；模型的真实性要靠后续论文数据与行为实验验证。代码中应有 `SpeciesDefinition`、`BehaviorParameterSet`、`ParameterSource`：

- `ENGINEERING_FIXTURE`：为了测试正确性填入的数值，不可宣称真实。
- `LITERATURE_CALIBRATED`：有明确文献、实验条件、单位、拟合方法的数值。
- `USER_MODIFIED`：玩家在实验世界中修改的参数，不能再与自然基准混淆。

物种特定的触角感知、信息素沉积、发育和巢室构建细则不直接硬编码到全局调度器。

## 2. P0 最小行为集合

| 高层任务 | 局部可用信息 | 动作 | 成功/失败条件 |
|---|---|---|---|
| `Explore` | 近处地形、食物/信息素线索、身体需求 | 局部搜索、合法路线移动 | 进入可达新位置；发现食物由实际接触触发 |
| `CollectFood` | 感知到且实际可触及的食物源 | 申请采集数量 | 资源/携带容量/接触合法；可部分成功 |
| `ReturnNest` | 有限路线记忆、合法通行网络、局部线索 | 移动、重新找路 | 实际抵达可通行巢穴区域 |
| `Trophallaxis` | 近处同巢个体、双方嗉囊与生理状态 | 提议液体转移 | 接触距离、容量、双方存活且合法 |
| `FeedBrood` | 附近幼体需求、可用营养 | 申请喂食 | 幼体实际接收并更新营养账 |
| `Rest` | 当前局部任务刺激弱或身体需低活动 | 降低额外活动消耗 | 遇合法刺激后可醒来 |
| `Excavate` | 当前可达挖掘前缘、土质/剩余材料、身体能力 | 切除小块真实土壤 | 物料账与几何事务提交一致 |
| `TransportSoil` | 工蚁持有的土粒、合法可达弃置区 | 搬运/弃置 | 土粒从携带→弃置；不凭空消失 |

不做常驻人工“侦察蚁职业”。个体探索偏好为可变阈值，受年龄/经验/状态约束。蚁后不运行工蚁任务状态机。卵/蛹不执行成年动作。

## 3. 局部决策候选（可解释、可测试）

高层任务评分：`S_i(a) = b_species(a) + Σ_k w(a,k) * cue_i(k) + inertia_i(a) - threshold_i(a)`。

- 候选任务必须先经过合法性筛选，例如距离、品级、生命阶段、能量和资源条件。
- 用确定性 PRNG 的概率选择或明确阈值触发；必须让相同 seed/配置可复现。
- 任务有最短持续时间、冷却和可抢占条件；突发危险可以优先触发中断。
- `PerceptionSampler` 只能从工蚁附近采样；禁止直接传入整张世界地图的食物坐标作为“感知”。

**首版最低实现**可以先使用特意简化的 `Explore/Collect/Return/Rest`，在后续批次增加内巢任务；每个新任务都必须先有 ActionProposal、事务成功事件和至少一个失败场景测试。

## 4. 信息素与路径记忆的边界

- 信息素存在于可行走表面，不等于三维空气中任意位置的全局路径导航。
- 采用局部沉积与衰减 `C(t+Δt)=C(t)e^{-λΔt}`；若启用扩散，必须验证空间/时间数值稳定性。
- 路线记忆保存少量路径/地标关联、强度和上次强化时刻；不使用人类语言存储“内心想法”。
- 信息素与记忆会共同影响路线选择，但不保证所有工蚁总选最短路径。
- 拥挤负反馈和路线记忆对黑园蚁有研究依据，但具体数值须单独标定。来源见 `07_References.md`、`04_Biology_and_Social_Simulation.md`。

## 5. 生理、食物和生命阶段

- 食物的水、碳水、蛋白按 µg 分开。总体质量还包括可选 `otherMassUg`，防止相加超过食品总量。
- 成年工蚁身体可用能量 J 与嗉囊内容物 µg 分开；交哺通过相同事务减少供者、增加受者。
- `Egg/Larva/Pupa/Adult/Dead` 连续 AntId；阶段切换可能由营养、温湿度与时间积分触发。
- P0 初始可以注入一只蚁后、32 工蚁和 12 幼体，仅为机制覆盖的受控 fixture，不是野外实测群落结构。
- 产卵、发育/死亡相关方程需要版本化参数；未标定时只验证逻辑与守恒，不能声称真实发育时间或死亡率。

## 6. 三维挖掘实验边界

最小实验需要：一个真实三维腔体、入口、可达土壤 `Frontier`、可运土路径和弃置位置。挖掘是工蚁提出的局部材料切除请求，不是 `BuildRoom` 命令。通过明确 material ledger 处理重叠切除、搬运、弃置、回填；空腔连通必须由几何净空确认。

初期可以使用一个轴对齐土块 + 球/胶囊形小切除原语作为工程验证，**不得将这种原语形状宣传为黑园蚁必然挖掘出的真实巢室几何**。

## 7. 场景与可复现测试

`scenarios/p0_smoke.json`：空或极少个体，验证创建/推进/种子/事件/快照/恢复/无 LLM。

`scenarios/p0_biology_fixture.json`：一只蚁后、32 工蚁、12 幼体，真实坐标、两处资源、初始巢室、可挖前缘、fixture 参数及 1 个观测窗口；P0 逐批启用行为。

配置中的 `model_status=ENGINEERING_FIXTURE` 必须伴随输出报告。工程固定 seed 下可重现一次路线，真实生物学合理性则需要多个 seed、不同条件和真实文献比对。

## 8. 实验指标与退出条件

| 实验 | 条件 | 至少输出 |
|---|---|---|
| F1 搜索 | 无预先巢外信息素 | 首次真实发现时间、探索覆盖率、找到食物的个体 ID |
| F2 信息素 | 关闭/开启踪迹 | 返巢次数、路径利用率、食物获得量 |
| F3 路线记忆 | 关闭/开启有限记忆 | 重新访问次数、偏离或失败记录 |
| N1 营养 | 充足/限制蛋白 | 实际蛋白入流、幼体状态，禁止无来源增长 |
| N2 交哺 | 受体嗉囊有/无容量 | 真实转移质量、供受双方账本 |
| G1 挖掘 | 单次/重叠挖掘 | 几何交集移除量、dry mass ledger、revision |
| G2 连通 | 同深孔口/不同深隧道交叉 | 导航净空与真实几何一致 |
| S1 生命周期 | 受控发育跨阈值 | AntId 保持、阶段事件一次、存活人口统计一致 |

**重要**：P0 机制验收只说明算法完整/守恒/因果/复现已测。物种真实性还需要另外的科学标定门禁，不允许用“行为看起来像蚂蚁”代替验证。
