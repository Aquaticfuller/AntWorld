No chemical unit, time, probability, coefficient, geometry or species calibration is transferred directly to AntWorld. All implementation values remain `ENGINEERING_FIXTURE`. ## Engineering inference, not an empirical law

The current model combines a heading bonus, a visited-cell penalty and a zero-probability predecessor veto. The first two are graded; the veto overrides any finite local signal. A narrow candidate change is to lift only that veto when the predecessor is the only visible adjacent signal, leaving its existing visited penalty and all other weights intact. This would permit, not require, a local correction. It needs no direction-marked pheromone, global source, new memory, field gradient to food or reward oracle. The rule also operates near trail ends, so repeated endpoint turning and reduced progress must be measured as potential costs.

The studies motivate testing local correction and separating behavioral endpoints; none establishes this exact Boolean condition or the numerical fixture. Larger changes such as antennal steering, continuous turning angles, changed sensory radius, dose-response calibration, reinforcement density or route learning remain outside this minimal candidate. If a condition shows no benefit, retain it. Read document 29 for the frozen protocol and S2_2_RESULTS.md for executed evidence.
