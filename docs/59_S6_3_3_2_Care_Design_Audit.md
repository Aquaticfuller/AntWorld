## Frozen implementation order and invariants

1. Add host-only scopes for actual care query work, opportunity recording and checkpoint history encoding. Record the same-colony reference before changing query behavior. Prefer the already maintained contact bucket/tree index for complete living-neighbor candidates in non-geometry worlds with bounded contacts. Query only candidate buckets intersecting a conservative 3D box, apply the same radius, geometry and role filters and sort by stable EntityId before selection and fact generation. Retain a fallback where the index is absent. The optimization must keep the original eligible set and fact order. No new checkpoint state for the index.
2. Add an explicit opt-in Species fidelity profile, append act IDs for pickup, placement and shelter return, and create schema 13 / physics 15 for its continuation. Keep old worlds byte-compatible. Keep the old 1 mm maximum step as a spatial/sensing limit. Schedule translating acts with the ceiling of distance divided by the caste's independent loaded or unloaded speed, in integer milliseconds, capped by the world speed limit. Arrangement uses its own manipulation duration with a speed floor on duration if needed. Apply actual 3D swept constraints and limit surface-only care sweeps to walkable cells. A segment changes authoritative positions only when it commits. Pickup, carried custody, motion and unload have independent evidence. Retain one local load through segments, with an exclusive journaled lock. A real release or interruption clears it. No global target path or nutrient gain is implied.
3. Separate an ordinary decision from continuation. The baseline has decision interval 60 s and probabilities 0.5, 0.25 and 0.8, all inherited fixtures. With no local target, a bounded sequence of up to eight 1 mm cardinal search steps uses its own deterministic local observations. A newly detected target or an interruption ends this search sequence. Keep one previously visited pickup location and an explicit re-search pause. After a settled manipulation or completed worker contact without a continuing episode, the ordinary interval controls reevaluation. Idle bouts already consume that interval. Keep recognition after local discovery. In a declared neutral assay only, permit foreign larvae/pupae that are displaced to be approached and carried to the shelter proxy. Preserve donor ColonyId, reject foreign feeding and avoid any adoption mechanic. Outside the assay retain own-colony care. A disc centered in the test arena gates care motion only.
4. Integrate a bounded care motor lease into existing individual `AutonomyWake`. Workers can enter a locally eligible care option alongside rest, foraging, resource nursing and excavation. Retain existing urgent, ownership, dwell, and current useful gift-continuation checks. Starting a lease uses the ordinary transition cleanup without a simultaneous NutritionWake. The lease covers one manipulation or pickup-to-placement episode, then yields after a real local shelter return. Restore regular decisions without re-enrollment. A blocked return retains the last committed location and the known shelter, permitting a later physical retry. Workers keep acquired route memory and actual carried food/soil preclude takeover. Queens use only local care and their existing individual reproduction. Local completed worker contact mediates a reversible contextual tendency. True age effects, callow maturation and the mediator of B01 worker inhibition remain unknown.
5. Test the new variants before comparing endpoints. Require local geometry and collision checks for both carrier and brood, sorted competition, exact restoration of held custody, interruption and retry rollback, same ant and brood identity through save/death, and unchanged resource ledgers. Require legacy event/scan equality with the original archives and a clean build. Commit diagnostics and document any implementation correction that affects a previously measured outcome.
