# R0-r1 measured data

The ten `witnesses` ZIPs contain original Core initial checkpoints, terminal frames, and complete length-prefixed canonical facts. A flattened archive roster and the individual member manifests identify those bytes. The compact `diagnostics` trees retain the complete per-cut census, individual summaries, geometry edits, failure outcomes and per-case acquisition identities. Large unselected fact streams were hashed during acquisition. The runners reproduce them from the recorded native commands. `tables` are derived from the compact diagnostics by `tools/summarize_r0_r1.py`.

The two cell ranges differ: 34 primary 24-hour excavation runs all finished. The optional 90-hour extension has five complete runs, one deliberately stopped after its verified 42-hour anchor and two unstarted cases. `receipts/extended-execution.json` records every outstanding extension, the actual checkpoint digest and the stopping decision. It does not enter either other denominator.

The pilot directories are non-normative. The motion pilot and first retry retain the loss of delivery and all resulting deaths with the early draft of the motor. They uncovered the missing first-review approach from a brood position. The third pilot verified the correction before the scored matrix. The first short digging pilot failed during setup because the social fixture used zero stage weights. That fixture was replaced by the no-food/no-foraging-opportunity case with valid task weights. The subsequent 90-second digging pilot contains the six-hour run at 300 workers. It exceeded 1 GiB peak resident memory, so the formal assessment used the inherited thirty-minute work clock before any formal observations. Its high event count is retained.
