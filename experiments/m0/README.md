# MicroWorld evidence

`demo` contains five complete native ZIP witnesses selected in advance. Each includes the verified initial checkpoint, terminal frame, full canonical fact stream, geometry edits, daily individual and ledger cuts, exact inputs and a member receipt. The outer archives are listed by SHA-256. Use `tools/verify_m0.py` to recheck them. Pass `--replay` with a fresh durable run to compare the stable members across hosts. ZIP packaging and elapsed-time records can vary with the host.

`portable-demo` is the default playable collection. The same five selectors capture the versioned fix to the native care clock. Use `tools/verify_m0.py experiments/m0/portable-demo --portable-care` to qualify them. The earlier archives remain the original, unmodified evidence. Their platform drift and its fix are recorded in the [native replay report](../../research/m0/M0_PORTABILITY_RESULTS.md).

`evidence/analysis` covers the 28 frozen cases. `worlds.csv` has one row per world. `cohort-trajectories.json` follows the first 24 hours of actual laying, including unfed, dead and right-censored individuals. `worker-windows.json` gives the first day and the first four days of the first three naturally emerged workers in each balanced demo. Each physiology snapshot retains its sampling time. Foundress ration mass and uptake mass are distinct. `evidence/runs` retains the first two failing recovery probes, the original roster with four rejected configurations, the resulting ablation retry, and both successful recovery collections.

The remaining original ZIPs are generated by `tools/run_m0.py` and were retained on the experiment host in `out/m0-work/formal`, `out/m0-work/ablation-fix` and `out/m0-work/final-recovery`. The full original archive hashes and file-level receipts are in this tree. The Windows guide names the five self-contained public examples. See [the report](../../research/m0/M0_RESULTS.md) for reproduction and interpretation.
