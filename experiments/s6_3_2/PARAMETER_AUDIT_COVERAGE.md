# Parameter coverage and interpretation

`tools/inventory_s6_3_2.py` inventories every current field in 16 configuration/seed/control structs (119 fields), default declarations, typed/positional aggregate initializers, API argument aggregates, typed-return aggregates and member/whole-variable overrides throughout `cpp/include`, `cpp/src`, `cpp/apps` and `cpp/tests`. `source_parameters.csv` preserves expressions and locations; `configuration_uses.csv` retains anchors for indirect copies/builders; `coverage.json` hashes every scanned source and records unresolved ownership. This is a lexical inventory with delimiter handling, not a C++ semantic evaluator. Symbolic/scenario expressions remain expressions; zero-initialized composites are not scalar biological zeroes.

`tools/provenance_s6_3_2.py` requires explicit unit and meaning metadata for **every** schema field; a missing/extra field fails the check. It joins all source expressions, including regression overrides, to the reviewed evidence. Supplemental records retain fixture numeric declaration/control contexts, all scenario JSON leaves, and manually anchored hard-coded biological/algorithmic rules. Mixed contextual lines are deliberately labelled MIXED and are not claimed to be resolved scalar species parameters. IDs, hashes, loop counts and memory budgets are computational controls; none is biological calibration. Exact API transfer defaults and finite memory limits are included in the hard-coded registry.

Manual reconciliation covers all application fixture headers (S2/S2.1/S2.2 surface/trail controls, S3 nutrition/lifecycle, S4 geometry, S5 storage, S6/S6.1/S6.2 nutrition/contact, S6.3 long-term and S6.3.1 queen controls), experiment/benchmark applications and all test overrides. S6.3.2's new diagnostic profile is included. `scenarios/p0_biology_fixture.json` is design metadata, not proof that a runtime biology model implements those conditions. Composite nutrient vectors list component units; coordinate vectors use the stated world axes. Source hashes and `--check` prevent stale provenance after later edits.

Evidence grade D applies to the **adopted number or rule**, even when related A/B/C research supports its qualitative intent. Related evidence has a separate column. No paper is cited as measuring a value it does not measure. Blank DOI means no relevant measured source identified, not a missing numeric zero. Current runtime values follow defaults plus the recorded scenario override; the CSV does not claim to enumerate an unbounded space of user inputs. Lexical name resolution cannot prove scope/type equivalence in arbitrary future C++; ambiguous cases fail manual review rather than acquire biological authority.

Key quantitative checks are in BIOLOGICAL_VALIDATION_REPORT.md. For example, 100 ug dry soil per (0.5 mm)^3 corresponds to 0.8 g/cm^3 dry bulk density; this is an engineering substrate assumption, not B13's measured 1.08 g/cm^3 setup. A 4 mg cargo limit is separate from a 1 mg crop limit and cannot be equated to worker body mass. Trail units have no identified chemical mass mapping. Six-hour task assignment is not six hours of observed activity. The state matrix supplies nonnumeric ordering/priority/eligibility rules that a numeric configuration scan alone cannot describe.

Reproduce with `python tools/inventory_s6_3_2.py` and `python tools/provenance_s6_3_2.py`; add `--check` to verify committed outputs. No biology or Core coefficient is modified by either tool.
